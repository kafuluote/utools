实用工具 0.5.0（Windows x64）

双击 exchange-tools.exe 即可打开，无需安装 Node.js 或 Rust。
需要 Microsoft Edge WebView2 Runtime；如果电脑缺少它，请使用安装包安装。

启动时自动恢复上次访问的选项卡；首次启动默认显示“汇率换算”。
启动时自动检查 GitHub 仓库 kafuluote/utools 的正式发布版，右上方也可手动“检查更新”。发现更高版本后显示更新说明并提示下载。下载在浏览器中完成，请关闭软件后运行安装包，或解压便携版使用；不会自动安装。启动检查失败不会打断工具使用，手动检查可查看错误或暂无发布版提示。
选项卡“Unix 时间转换”：实时显示当前时间戳，支持秒/毫秒切换、时间戳转北京时间、分项日期或 YYYYMMDDHHMMSS 快速日期转时间戳，以及各项复制。
北京时间固定 UTC+8，与电脑时区无关；支持 0 和负时间戳，校验闰年及无效日期。毫秒时间戳转日期保留毫秒，日期输入精度为秒。支持北京时间 0001–9999 年，全程本地计算，切换选项卡保留内容。
选项卡“汇率换算”：保留双向换算、币种交换和 API 配置。只有点击“刷新汇率”才联网，初始数据是示例汇率。
选项卡“本地二维码”：点击“图片解码”选择图片，也可拖放多张图片，或者复制图片/截图后按 Ctrl+V、点击“粘贴图片”。
选项卡“JSON 解析器”：左侧输入 JSON，右侧实时校验和高亮显示；支持格式化（Ctrl+Enter）、压缩、行号、折叠/展开、点击值编辑、保留转义、主题切换、全屏编辑、导入文件、复制和导出 .json。
长整数与重复键保留，不上传 JSON、不保存内容历史，切换选项卡保留本次输入。输入最多 100 万字符、10 万节点、256 层；导入文件最多 3 MB。结果最多显示 3000 行，复制和导出完整结果（最多 5 MB）。
一次最多 32 张图片。单张最多 20 MB、1600 万像素，单边最多 8192 像素。
支持 PNG、JPG、WebP、BMP、GIF、TIFF、ICO（GIF/TIFF 读取首帧或首张）。
图片在本机 Rust 后端解码，不上传，不会自动打开二维码中的网址，也不保存解码历史。
一张图片可识别多个标准二维码。可点击结果旁的复制图标，或“导出文本”保存 UTF-8 文本文件。
“继续解码”返回图片选择区；也可直接粘贴或拖放新图片替换结果。切换选项卡会保留本次结果。
平台专用码（如小程序码）不属于标准二维码；模糊、遮挡、过小的二维码可能无法识别。
非 UTF-8 内容会尝试 GB18030（界面标记为推测）；无法解释的二进制数据以十六进制展示。
